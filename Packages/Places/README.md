# Spellbound.Places

A place as typed layers kept in Unity serialization, composed by adjacency rules and validated and previewed through Core's authoring contract.

## Install

Add this line to `Packages/manifest.json`, replacing `<version>` with a release tag:

```
"com.spellboundstudios.places": "https://github.com/Spellbound-Studios/Places.git?path=/Packages/Places#v<version>"
```

The Spellbound window in Core installs it for you.

## Front door

`PlacesKit` is the entry point to everything this package offers.

## Rules

The binding rules are the line text at https://github.com/Spellbound-Studios/.github/tree/main/line
